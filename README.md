# ÚLTIMA LINHA — 1944

Estratégia narrativa 2D offline ambientada em cenários ficcionais sob contexto histórico da Segunda Guerra Mundial. A primeira fundação inclui campanhas de Exército, USAAF e Marinha, um laboratório de validação, motor de turno determinístico, IA local, save/exportação local e mapa renderizado em Phaser.

> Estado atual: fundação jogável de desenvolvimento. O conteúdo canônico completo do Lote 1 — rosters individuais, eventos, assets aprovados e todos os desfechos — permanece em produção.

## Executar

```bash
pnpm install
pnpm dev
```

## Verificar

```bash
pnpm test
pnpm build
```

Leia [architecture.md](architecture.md) antes de alterar motor, saves ou pacotes de missão.
